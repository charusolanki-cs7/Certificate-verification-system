# Code of Conduct

# Our Standards

Examples of behavior that contributes to a positive environment include:

- Using welcoming and respectful language
- Being supportive of other contributors
- Accepting constructive criticism gracefully
- Focusing on what is best for the community
- Helping beginners and new contributors
- Maintaining professionalism in discussions

Examples of unacceptable behavior include:

- Harassment or discriminatory language
- Trolling, insulting, or derogatory comments
- Personal or political attacks
- Public or private harassment
- Posting someone else's private information without permission
- Spam, inappropriate promotions, or malicious content
- Any behavior that could harm the community environment

---

# Contribution Rules

Before contributing, please ensure that you:

- Read the project documentation carefully
- Check existing issues before creating a new one
- Follow coding standards used in the project
- Write clean and understandable code
- Test your code before submitting a Pull Request
- Keep Pull Requests focused on a single issue or feature

---

# Pull Request Guidelines

- Create a separate branch for every issue
- Use meaningful commit messages
- Add comments where necessary
- Do not submit plagiarized code
- Ensure your Pull Request does not break existing functionality

Example:

```bash
git checkout -b feature/add-qr-verification
```
---

# Issue Guidelines

When creating issues:

- Use clear and descriptive titles
- Mention expected behavior
- Add screenshots/logs if necessary
- Avoid duplicate issues

---

# Maintainer Responsibilities

Project maintainers are responsible for:

- Reviewing Pull Requests fairly
- Maintaining a respectful environment
- Guiding contributors when needed
- Closing invalid or spam issues
- Enforcing this Code of Conduct

---

# Enforcement

Instances of abusive, harassing, or otherwise unacceptable behavior may be reported to the project maintainer.

Maintainers have the right to:

- Remove inappropriate comments
- Reject problematic Pull Requests
- Temporarily or permanently ban contributors violating the Code of Conduct

---

# Scope

This Code of Conduct applies within all project spaces, including:

- GitHub Issues
- Pull Requests
- Discussions
- Project documentation
- Community communication channels
